# 🚀 مدار (Madaar) - Digital Agency Landing Page

A modern Arabic digital marketing and web development agency landing page. Features a clean, professional design focused on showcasing services, business growth statistics, and customer testimonials.

---

## 🌟 Features

* **Hero Section:** Engaging introductory banner with a high-impact team vector image and clear call-to-action buttons.
* **Services Grid:** Structured breakdown of digital agency services (SEO, Digital Marketing, Branding, UI/UX Design, Web Development, & Performance Analytics).
* **Statistics Bar:** Interactive counter section highlighting key metrics (500+ Projects, 100+ Happy Clients, 4.9 Rating).
* **Client Testimonials:** Reviews and ratings from real clients building strong social proof.
* **RTL & Arabic Optimization:** Tailored interface with clean typography and right-to-left alignment.

---

## 🛠️ Built With

* **HTML5:** Semantic architecture with modern web layouts.
* **CSS3:** Custom  grid alignments, color schemes, and media query responsiveness.
